One sentence that explains the modern internet to a time traveler from 1800, built only from things a person from that year already knows — a road, towns, letters, books, voices:

> Picture a single road joining every town on earth, down which letters, books, and voices fly faster than a blink, so anyone may read, write, and speak with anyone, anywhere, at once.

The program writes that sentence (182 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` and self-checks the gate first: 1–200 characters, exactly one sentence, no word coined after 1800.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
